# CineStream

CineStream is a web application built for movie lovers to explore trending films, search for titles, save favorites, and find recommendations using AI.

## Features

- Browse trending and top rated movies.
- AI Mood Matcher to get movie suggestions based on text prompts.
- Search movies by title or genre.
- Save and manage favorite movies locally.

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- TMDB API
- Google Gemini API
